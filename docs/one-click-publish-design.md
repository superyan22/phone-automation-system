# 一键发布小红书系统架构

## 🎯 核心功能

用户在网页点击"一键发布小红书"，系统自动完成：
1. **数据抓取** - 从预设来源抓取最新招聘信息
2. **图片生成** - 自动生成封面图、内容图、岗位表图
3. **ADB发布** - 自动推送到手机并发布到小红书
4. **进度展示** - 实时显示任务进度
5. **结果展示** - 完成后显示发布截图

## 🔄 发布流程

### Step 1: 用户触发
- 点击"一键发布小红书"按钮
- 选择数据来源（或使用默认）
- 确认发布

### Step 2: 数据抓取 (30-60秒)
```
任务状态: data_fetching
进度: 0-30%
```
- 从 `recruitment_latest.json` 读取最新数据
- 或调用爬虫抓取新数据
- 验证数据完整性

### Step 3: 图片生成 (20-40秒)
```
任务状态: image_generating
进度: 30-60%
```
- 读取HTML模板
- 用真实数据填充模板
- Playwright渲染为PNG
- 生成：封面图 + 内容图 + 岗位表图

### Step 4: ADB推送 (10-20秒)
```
任务状态: pushing_to_phone
进度: 60-75%
```
- 清理手机旧图片
- ADB push新图片到手机
- 触发媒体扫描
- 验证图片已添加到相册

### Step 5: 小红书发布 (30-60秒)
```
任务状态: publishing
进度: 75-95%
```
- 打开小红书APP
- 点击发布按钮
- 从相册选择图片
- 填写标题和正文
- 点击发布
- 截图保存结果

### Step 6: 完成
```
任务状态: completed
进度: 100%
```
- 更新数据库记录
- 保存截图到服务器
- 推送完成通知
- 更新索引文件

## 🔧 技术实现

### 后端核心代码结构

```python
# publish_service.py - 发布流程核心
class PublishService:
    async def publish_one_click(self, data_source: str = "latest"):
        """一键发布流程"""
        task_id = create_publish_task()
        
        # Step 1: 数据抓取
        update_progress(task_id, "data_fetching", 0)
        data = await self.fetch_data(data_source)
        update_progress(task_id, "data_fetching", 100)
        
        # Step 2: 图片生成
        update_progress(task_id, "image_generating", 0)
        images = await self.generate_images(data)
        update_progress(task_id, "image_generating", 100)
        
        # Step 3: ADB推送
        update_progress(task_id, "pushing_to_phone", 0)
        await self.push_to_phone(images)
        update_progress(task_id, "pushing_to_phone", 100)
        
        # Step 4: 小红书发布
        update_progress(task_id, "publishing", 0)
        screenshot = await self.publish_to_xhs(data)
        update_progress(task_id, "publishing", 100)
        
        # 完成
        complete_task(task_id, screenshot)
        return task_id
```

### 前端核心代码结构

```tsx
// Publish/index.tsx - 一键发布页面
const PublishPage: React.FC = () => {
  const [task, setTask] = useState<PublishTask | null>(null);
  const [progress, setProgress] = useState(0);
  
  // WebSocket监听进度
  useEffect(() => {
    const ws = new WebSocket(`/ws/publish/${task?.id}`);
    ws.onmessage = (event) => {
      const data = JSON.parse(event.data);
      setProgress(data.progress);
      setTask(data.task);
    };
  }, [task?.id]);
  
  return (
    <div>
      <PublishButton onClick={handlePublish} />
      {task && <TaskProgress task={task} />}
      {task?.status === 'completed' && <PublishResult task={task} />}
    </div>
  );
};
```

## 📊 数据模型

### PublishTask
```python
class PublishTask:
    id: str                    # 任务ID
    status: str                # pending/running/completed/failed
    step: str                  # current_step
    progress: int              # 0-100
    data_source: str           # 数据来源
    title: str                 # 发布标题
    images: List[str]          # 图片路径
    screenshot: str            # 发布截图
    created_at: datetime       # 创建时间
    completed_at: datetime     # 完成时间
    error: str                 # 错误信息
```

## ⚠️ 注意事项

1. **小红书风控**：每次发布间隔至少30分钟
2. **手机连接**：确保ADB连接稳定
3. **图片清理**：发布后清理手机旧图片
4. **错误处理**：任何步骤失败都要回滚并通知用户
5. **截图保存**：发布成功后必须截图保存证据
